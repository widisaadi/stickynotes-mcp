A few steps, then you’re connected

Make the
connection.

Install the server, point your MCP client to it, and start with a simple request to list your notes.

  1. Install from source

    Run these commands in PowerShell.

  2. Configure your client

    Add the Python and server paths to your client’s MCP settings.

  3. Reconnect and try it

    Ask: “List my five most recently updated sticky notes.”

Before you begin: open Sticky Notes and create a note so its local database exists.

PowerShell
git clone https://github.com/widisaadi/stickynotes-mcp.git
cd stickynotes-mcp
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
Uses the repository source and a local Python environment.
JSON · mcpServers format
{
  "mcpServers": {
    "sticky-notes": {
      "command": "C:\\path\\to\\stickynotes-mcp\\.venv\\Scripts\\python.exe",
      "args": ["C:\\path\\to\\stickynotes-mcp\\server.py"]
    }
  }
}
Replace both example paths. Merge this entry with your existing client settings.

Need another config format? See the setup guide

The server edits the local Sticky Notes database. Close Sticky Notes and keep an independent backup before using write tools on important notes.

The practical details

A few things
to know.

The practical details before you connect.

Does it work on macOS or Linux?

The server targets Microsoft Sticky Notes’ Windows UWP database on Windows 10 and 11. Other operating systems and Sticky Notes editions with different storage formats are not supported by this implementation.

Which AI clients can use it?

Claude, Codex, Hermes Agent, and OpenClaw are the agents highlighted by this project. Use an MCP-compatible client or integration that can start a local stdio server. Configure it to run your virtual environment’s Python executable with the absolute path to server.py. The setup guide includes a shared JSON example and the settings needed for other formats.

Where do my notes go?

The server reads and writes the local plum.sqlite database. Retrieved notes are returned to your MCP client; its model provider and privacy settings determine what happens to that content afterward. This landing page has no access to your notes.

Will changes appear on my desktop immediately?

The server updates stored database content and flags. It does not directly control app windows or guarantee an immediate refresh or cloud sync. You may need to reopen Sticky Notes to see changes.

Can I recover a deleted note?

Deletion is soft by default, so restore_note can bring it back. A permanent deletion cannot be undone by that tool. The automatic backup is best-effort and overwritten before each mutation; keep your own backup for important data.

Is there a subscription?

The project’s source is available under the MIT license. There is no paid plan for this server. Your AI client or model provider may have its own costs. This is an independent project, not an official Microsoft product.
